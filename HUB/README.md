# Image Sonification with SuperCollider

In this workshop we will explore the possibility of sonifying images.

As popularized by Aphex Twin in his track "Windowlicker", the workshop will show how to turn images into sound.

The workshop will offer a short introduction in image conversion, for its usage in sound production, and an introduction to supercollider for basic algorithmic sound design.


## Required software:

* [SuperCollider](https://supercollider.github.io/downloads)
* [Processing](https://processing.org/download)
* [sccode](https://sccode.org/)
