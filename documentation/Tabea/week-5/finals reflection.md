# PROCESS & REFLECTION

Since the mid-term presentations, my collection of typographic code sketches has enlarged by many experiments. On the one hand, I experimented further with already used visual means, i.e. playing with the repetition of the same elements and animating them using trigonometric functions. On the other hand, I played with the proportions of characters using the scale-command and learned to work with the textToPoints-command. Thereby, my main focus was to push to the limit of typographic animations in p5 and to create aesthetically pleasing visuals. Now, the challenge was to bring Julian's and my snippets together and connect them with an overlaying topic. We realized that the single animations would get boring quickly, if they were just shown one by one. In the search for a solution, we stumbled upon different possibilities: letting the code change over time autonomously through audioreactive clauses, varying the colour of the visuals and displaying several snippets at once. We ended up including all three ways in our performance canvas to generate a large number of possible visual outputs by combining and stacking different snippets. First, we set up a canvas which is split up in three areas, each being drawn on an individual layer so that the different snippets run independently. We turned the code snippets into functions and included them in the canvas to turn them on and off or stack them easily. Also, we included some overlaying animations to add another dimension to the sketch. Experimenting with the "visual workshop" we created outputted very busy visuals which led us to our topic of the performance: the overwhelm. This topic resonates with our personal experience facing the hectic world situation as well as small-scale clashes of events and feelings in our personal lives. Julian then tried to reenact this hectic feeling with the music he produced using FL studio. He worked with fast-paced beats and the overlay of different sounds recreating the atmosphere of the visuals. 
Similarily to the course of the music, the concept for the performance is to start with little visual material and add more and more functions to create a very buys multi-layered visual at the climax. This mirrors how overwhelm forms psychologically: there's one thing needing your attention, there's a second, third, etc. and as more and more adds up, pressure builds and you end up feeling completely out of control. 
Overall, I am happy with our end result. For a next time, I would experiment broader in the beginning and then go about the end project in a more structured way by defining a clear concept first and letting myself be guided by it. At some point in our process, it was difficult to turn our visuals into one coherent output. It was very helpful to set up a new sketch with all functions which allowed us to start playing with the combinations of them. This ultimately laid the basis for our final "visual coding tool box" that can most definitely serve as a solid starting point for future coding projects.
